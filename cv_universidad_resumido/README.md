# CV Resumido Universidad (ES)

Este folder contiene un CV resumido orientado a presentacion universitaria, priorizando investigacion y docencia.

## Render command

```powershell
pixi run -e rendercv rendercv render .\cv_universidad_resumido\Agustin_Corbat_CV_Universidad_Resumido.yaml --design .\design_moderncv_es.yaml --locale-catalog .\locale_en.yaml
```

## Criterios aplicados

- Prioriza roles de investigacion y docencia.
- Incluye roles de analista de bioimagenes y Jefe de Trabajos Practicos de los ultimos 3 anos.
- Incluye todas las publicaciones listadas en la base de datos.
- Incluye cursos y clases dictados desde fines de 2024 en adelante.
- Disenado para formato resumido (objetivo: ~2 carillas, sujeto al render final y espaciado tipografico).
